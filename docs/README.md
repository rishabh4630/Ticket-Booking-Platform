# Documents

Original documentation and database material for the TSN Ticket Booking
project, kept as supplied with the project.

| File | What it is |
|------|------------|
| `TransServiceNetMainDoc1.doc` | Main project documentation (Word document) |
| `tables/tnstb.sql` | Oracle table definitions for all masters and transactions |
| `tables/tnstb.txt` | Same table material in plain text |
| `dfd-erd/TSNDFDmod1.ppt`, `TSNDFDmod2.ppt` | Data-flow diagrams (modules 1 and 2) |
| `dfd-erd/TSNERD.ppt`, `TSNERDmod1.ppt`, `TSNERDmod2.ppt` | Entity-relationship diagrams |

The tables in `tables/tnstb.sql` are the basis for the SQLite schema used
by the web version in `../cross_platform_web/` (Oracle types converted to
SQLite integer/text).
